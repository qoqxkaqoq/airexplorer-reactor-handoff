【关键技术结论（83 版实验的答案）】
  1. NETReactor 保护层: 引导机(37KB 状态机)、TLS 链、运行时生成体
  2. 运行时生成体不可静态恢复: Invoke 等方法在所有二进制中 RVA=0，
     由 Reactor 原生层运行时生成 → 静态重建成死路
  3. 出窗路线（最终成功方案）:
     SearchAdapter 语义重写 → 跳过 AV 源(ValidateDynamicEncryptor)
     → 干净 ApplicationContext + ExecuteExplorer 跑消息循环
     → TreeFunction 直启(构造最小化避开 Reactor 加密资源)
     → set_Text 设置标题
  4. 嵌入资源 6 项均为 Reactor 加密格式，标准 ResourceManager 读取必败
